# Лабораторна 4: Класи та об'єкти IRIS

Предметна область: Галерея/Музей

Реалізація UML-діаграми з ПР3 як класів InterSystems IRIS. Кожен клас відповідає сутності предметної області та містить властивості, індекси та відношення згідно з діаграмою.

## Структура проекту

```
Gallery/
├── Person.cls        — абстрактний базовий клас з ім'ям та датою народження
├── Artist.cls        — художник (extends Person), має біографію та твори
├── Location.cls      — локація (%SerialObject) для вбудовування у виставку
├── Exhibition.cls    — виставка з датами проведення та списком експонатів
├── Exhibit.cls       — експонат (child) з позицією та тегами
├── Artwork.cls       — твір мистецтва з інвентарним номером та оцінками
└── PopulateData.cls  — заповнення тестовими даними
```

## Запуск

```objectscript
Do ##class(Gallery.PopulateData).Run()
```

Скрипт створює повний набір пов'язаних об'єктів: художників з біографіями, їхні твори різних технік, виставки з локаціями та експонати з тегами.

## Тестові дані

Скрипт `PopulateData.Run()` створює:

- **5 художників** — Леонардо да Вінчі (Італія, 1452), Ван Гог (Нідерланди), Моне (Франція), Пікассо (Іспанія), Рембрандт. Кожен має біографію у потоці Biography.
- **10 творів** — по 2 на художника: Мона Ліза та Таємна вечеря (Леонардо), Зоряна ніч та Соняшники (Ван Гог), і т.д. Заповнені technique, dimensions, ratings.
- **3 виставки** — Майстри Відродження, Імпресіонізм, Модернізм. Кожна з вбудованою Location (building, hall, floor).
- **8 експонатів** — прив'язані до виставок через parent-children. Мають теги та displayNotes.

## Реалізовані елементи

**Успадкування** — Artist extends Person, отримуючи властивості firstName, lastName, birthDate.

**Вбудований об'єкт** — Location зберігається безпосередньо в Exhibition (building, hall, floor).

**Потік** — Artist.Biography містить розгорнуту біографію художника.

**Колекції** — Exhibit.Tags (список тегів), Artwork.Ratings (масив оцінок від різних критиків).

**Відношення** — parent-children між Exhibition та Exhibit забезпечує каскадне видалення; one-many між Artist та Artwork дозволяє художнику мати багато творів.

**Обмеження** — Required, Unique на ключових властивостях, MinVal/MaxVal на числових.
