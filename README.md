# Лабораторна 1: Реалізація принципів ООП

Предметна область: Галерея/Музей

Програма на Python моделює систему управління художніми творами. Ієрархія класів побудована навколо абстрактного класу `ArtObject`, від якого успадковуються `Painting` (картина) та `Sculpture` (скульптура). Кожен нащадок перевантажує методи `getDescription()` та `getInfo()`, додаючи специфічні для типу деталі — техніку виконання для картин чи матеріал для скульптур.

## Інкапсуляція

Приватні властивості `_estimatedPrice` та `_exhibits` захищені від прямого доступу. Метод `_validatePrice()` перевіряє коректність ціни перед збереженням. Це гарантує, що бізнес-логіка (наприклад, ціна не може бути від'ємною) завжди виконується.

## Типи властивостей

- Прості типи: `title` (str), `creationYear` (int), `estimatedPrice` (float)
- Посилання на об'єкти: кожен `ArtObject` містить посилання на `Artist`
- Колекції: `dimensions` (список розмірів), `visitorComments` (масив відгуків)

## Демонстрація

Створено художників (Моне, Роден), їхні твори з заповненими властивостями. Виклик методів показує поліморфну поведінку — один інтерфейс, різна реалізація для картин та скульптур.
